ECEN 248 Labs

Designed, simulated, and implemented combinational and sequential digital logic circuits from physical hardware to FPGA deployment. Wired and tested 7400-series TTL logic gates, multiplexers, decoders, and a 4-bit arithmetic logic unit (ALU) on breadboards using DC power supplies and digital multimeters. Transitioned to hardware description modeling using Verilog HDL in Xilinx Vivado to write testbenches, verify simulation waveforms, and synthesize finite state machines (FSMs), counters, and clock dividers onto an FPGA board.
